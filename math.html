Définition d'une suite

Qu'est-ce qu'une suite ?
Une suite numérique est une fonction définie sur les entiers naturels ℕ (ou une partie de ℕ) à valeurs réelles. On la note généralement (un) ou u.

Pour tout entier naturel n, un est appelé le terme de rang n ou le terme général de la suite.
On note u0 le premier terme, u1 le deuxième terme, etc.

Modes de définition

1️⃣ Définition explicite

La suite est définie par une formule exprimant un en fonction de n.
Exemple :
un = 3n + 5
Alors : u0 = 5, u1 = 8, u2 = 11, u3 = 14...

2️⃣ Définition par récurrence

La suite est définie par :
  • Son premier terme (condition initiale)
  • Une relation de récurrence exprimant un+1 en fonction de un
Exemple :
u0 = 2 et un+1 = 2un - 3
Alors : u1 = 2×2 - 3 = 1, u2 = 2×1 - 3 = -1...

Suites arithmétiques

Définition
Une suite (un) est arithmétique s'il existe un nombre réel r (appelé raison) tel que :
un+1 = un + r

🔑 Propriétés importantes

Terme général :
un = u0 + n × r
Ou plus généralement :
un = up + (n - p) × r
Somme des n premiers termes :
S = u0 + u1 + ... + un = (n+1) × (u0 + un) / 2
Exemple concret :
Suite u0 = 7 avec r = 3
  • u5 = 7 + 5×3 = 22
  • Somme des 6 premiers termes : S = 6 × (7 + 22) / 2 = 87

Suites géométriques

Définition
Une suite (un) est géométrique s'il existe un nombre réel q non nul (appelé raison) tel que :
un+1 = un × q

🔑 Propriétés importantes

Terme général :
un = u0 × qn
Ou plus généralement :
un = up × qn-p
Somme des n premiers termes (si q ≠ 1) :
S = u0 × (1 - qn+1) / (1 - q)
Exemple concret :
Suite u0 = 5 avec q = 2
  • u4 = 5 × 24 = 80
  • Somme des 5 premiers termes : S = 5 × (1 - 25) / (1 - 2) = 155

Sens de variation

Suite croissante : un+1 ≥ un pour tout n

Suite décroissante : un+1 ≤ un pour tout n

Suite constante : un+1 = un pour tout n
Pour étudier les variations, on peut :
  • Étudier le signe de un+1 - un
  • Comparer un+1 / un à 1 (si un > 0)
  • Étudier la fonction f(x) si un = f(n)

Suites majorées, minorées, bornées

Suite majorée : Il existe M tel que un ≤ M pour tout n

Suite minorée : Il existe m tel que un ≥ m pour tout n

Suite bornée : La suite est à la fois majorée et minorée
