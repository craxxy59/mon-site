Suites — Vocabulaire

Modes de génération, notations
Notations
u(n) ou uₙn-ième terme de la suite (u(n))
(uₙ) ou (u(n))La suite toute entière
uₙ = f(n)Formule explicite : le terme dépend directement du rang n
uₙ₊₁ = f(uₙ)Relation de récurrence : chaque terme dépend du précédent
Sens de variation
Croissante
∀n, uₙ₊₁ ≥ uₙ
Décroissante
∀n, uₙ₊₁ ≤ uₙ
Minorée / Majorée
∃m, ∀n : m ≤ uₙ  /  uₙ ≤ M
Limite (intuition)
lim uₙ = L  : uₙ se rapproche de L quand n → +∞
lim uₙ = +∞  : uₙ devient arbitrairement grand
⚠ Aucune formalisation de la limite n'est au programme — intuition uniquement.
+r

Suite arithmétique

Raison r constante
Définition
uₙ₊₁ = uₙ + r
r = raison (constante) ; accroissements constants
Terme général
Depuis u₀
uₙ = u₀ + n·r
Depuis uₚ (rang p quelconque)
uₙ = uₚ + (n − p)·r
Sommes
Somme de p à n (nb termes = n−p+1)
S = (n−p+1) × (uₚ + uₙ) / 2
premier terme + dernier terme, divisé par 2, × nb de termes
Entiers de 1 à n
1 + 2 + 3 + … + n = n(n+1)/2
Entiers de 0 à n
0 + 1 + … + n = n(n+1)/2
Variations
r > 0 ⟹ suite croissante  |  r < 0 ⟹ décroissante
Lien avec fonctions affines
f(n) = rn + u₀  : droite de pente r
×q

Suite géométrique

Raison q constante
Définition
uₙ₊₁ = q·uₙ
q = raison, q ≠ 0 ; évolutions à taux constant
Terme général
Depuis u₀
uₙ = u₀ · qⁿ
Depuis uₚ
uₙ = uₚ · qⁿ⁻ᵖ
Somme géométrique
q ≠ 1
1 + q + q² + … + qⁿ = (1 − qⁿ⁺¹) / (1 − q)
Suite générale, q ≠ 1
u₀ + u₁ + … + uₙ = u₀ · (1 − qⁿ⁺¹) / (1 − q)
q = 1
Somme = (n+1) · u₀
Limites
|q| < 1 ⟹ qⁿ → 0
q > 1 ⟹ qⁿ → +∞
q < −1 ⟹ (qⁿ) diverge (oscille)
Lien avec exponentielle
Pour tout réel a, (e^(na)) est géométrique de raison eᵃ
Δ

Polynômes du 2nd degré

ax² + bx + c, formes, racines
Trois formes
Développée réduite
f(x) = ax² + bx + c
Canonique
f(x) = a(x − α)² + β
α = −b/(2a)  ·  β = f(α) = c − b²/(4a) = −Δ/(4a)
Factorisée (si Δ ≥ 0)
f(x) = a(x − x₁)(x − x₂)
Discriminant & racines
Discriminant
Δ = b² − 4ac
Δ > 0 — deux racines réelles distinctes
x₁ = (−b − √Δ)/(2a)    x₂ = (−b + √Δ)/(2a)
Δ = 0 — racine double
x₀ = −b/(2a)
Δ < 0 — aucune racine réelle
f(x) > 0 si a > 0,   f(x) < 0 si a < 0
Relations de Viète
x₁ + x₂ = −b/a
x₁ · x₂ = c/a
Utile pour trouver des racines entières mentalement
Identité de complétion du carré
x² + 2ax = (x + a)² − a²
Parabole (axe de sym., sommet)
Axe de symétrie : x = α = −b/(2a)
Sommet : S(α, β)
minimum si a > 0, maximum si a < 0

Dérivation — Point de vue local

Taux de variation, tangente
Taux de variation
Taux de variation de f entre a et a+h
τ = [f(a+h) − f(a)] / h
= pente de la sécante passant par (a, f(a)) et (a+h, f(a+h))
Nombre dérivé
Définition intuitive
f'(a) = limite du taux de variation quand h→0
Interprétations
Pente de la tangente en a
Vitesse instantanée (cinématique)
Coût marginal (économie)
Équation de la tangente en x = a
y = f(a) + f'(a)·(x − a)
droite de pente f'(a) passant par (a, f(a))
Fonction valeur absolue
x ↦ |x| : non dérivable en 0
taux de variation → +1 ou −1 selon le signe de h → limite inexistante

Fonction exponentielle

Définition, propriétés, modèles
Définition (admise)
exp est l'unique fonction dérivable sur ℝ telle que :
f' = f    ET    f(0) = 1
Notation
exp(x) = eˣ    où e ≈ 2,718…
Propriétés algébriques
eˣ⁺ʸ = eˣ · eʸ
eˣ⁻ʸ = eˣ / eʸ
(eˣ)ⁿ = eⁿˣ
e⁻ˣ = 1/eˣ
e⁰ = 1    e¹ = e
Signe & variations
eˣ > 0 pour tout x ∈ ℝ
x ↦ eˣ est strictement croissante sur ℝ
Limites & croissances comparées
lim(x→+∞) eˣ = +∞
lim(x→−∞) eˣ = 0
lim(x→+∞) eˣ/xⁿ = +∞   (l'exponentielle l'emporte)
lim(x→+∞) xⁿ·e⁻ˣ = 0

Solution générale de y' = ay

u·v

Produit scalaire

Définitions, bilinéarité, orthogonalité
Définitions
Via cosinus
u⃗·v⃗ = ‖u⃗‖·‖v⃗‖·cos θ
θ = angle entre u⃗ et v⃗
Via projection orthogonale
u⃗·v⃗ = ‖u⃗‖·‖v⃗‖·cos θ = ‖u⃗‖ × (proj. de v⃗ sur u⃗)
En base orthonormée
u⃗(x₁,y₁)·v⃗(x₂,y₂) = x₁x₂ + y₁y₂
Via normes
u⃗·v⃗ = (‖u⃗+v⃗‖² − ‖u⃗‖² − ‖v⃗‖²) / 2
Propriétés (bilinéarité, symétrie)
u⃗·v⃗ = v⃗·u⃗   (symétrie)
(u⃗+v⃗)·w⃗ = u⃗·w⃗ + v⃗·w⃗   (distributivité)
(λu⃗)·v⃗ = λ(u⃗·v⃗)
Norme au carré
‖u⃗‖² = u⃗·u⃗ = x² + y²
Développements utiles
‖u⃗+v⃗‖² = ‖u⃗‖² + 2u⃗·v⃗ + ‖v⃗‖²
‖u⃗−v⃗‖² = ‖u⃗‖² − 2u⃗·v⃗ + ‖v⃗‖²
Orthogonalité & collinéarité
u⃗ ⊥ v⃗  ⟺  u⃗·v⃗ = 0  ⟺  x₁x₂+y₁y₂ = 0
u⃗ ∥ v⃗  ⟺  x₁y₂ − y₁x₂ = 0
Formule d'Al-Kashi (généralisation de Pythagore)
BC² = AB² + AC² − 2·AB·AC·cos(Â)
Se démontre avec le produit scalaire : BC⃗ = AC⃗ − AB⃗
Ensemble des M tels que MA⃗·MB⃗ = 0
Cercle de diamètre [AB]
M voit AB sous un angle droit ⟺ MA⃗·MB⃗ = 0 ⟺ M est sur le cercle de diam. AB

P(A|B)

Probabilités conditionnelles

Arbres, indépendance, Bayes
Vocabulaire fondamental
ÉvénementSous-ensemble de l'univers Ω
Univers ΩEnsemble de toutes les issues possibles
Complémentaire ĀÉvénement contraire : P(Ā) = 1 − P(A)
Événements incompatiblesA∩B = ∅ ⟹ P(A∪B) = P(A)+P(B)
Partition de ΩSystème complet d'événements B₁,…,Bₙ disjoints dont l'union = Ω
Probabilité conditionnelle
Notation : PA(B) ou P(B|A)
P(B|A) = P(A∩B) / P(A)   (P(A) ≠ 0)
Règle du produit (arbre)
P(A∩B) = P(A) · P(B|A)
Formule des probabilités totales
P(A) = P(A|B)·P(B) + P(A|B̄)·P(B̄)
Cas général (partition B₁,…,Bₙ)
P(A) = Σ P(A|Bᵢ)·P(Bᵢ)
Formule de Bayes
P(B|A) = P(A|B)·P(B) / P(A)
Attention : P(A|B) ≠ P(B|A) ! (erreur fréquente des faux positifs)
Indépendance
A et B indépendants ⟺ P(A∩B) = P(A)·P(B)
A⊥B ⟺ P(B|A) = P(B)
X

Variables aléatoires réelles

Loi, espérance, variance, écart-type
Définitions
Variable aléatoire XFonction de l'univers Ω vers ℝ associant un nombre à chaque issue
Loi de XTableau donnant toutes les valeurs xᵢ et leurs probabilités P(X=xᵢ)
{X = a}Événement : «X prend la valeur a»
{X ≤ a}Événement : «X est inférieur ou égal à a»
Espérance (moyenne théorique)
E(X) = Σ xᵢ · P(X = xᵢ)
Valeur moyenne à long terme · Mise pour un jeu équitable
Linéarité
E(aX + b) = a·E(X) + b
Variance & écart-type
Variance
V(X) = Σ (xᵢ − E(X))² · P(X = xᵢ)
Formule de König-Huygens
V(X) = E(X²) − [E(X)]²
Écart-type
σ(X) = √V(X)
Mesure la dispersion autour de la moyenne
Propriétés
V(aX+b) = a²·V(X)
Σ P(X = xᵢ) = 1   (somme des prob. = 1)
B(n,p)

Loi binomiale

Schéma de Bernoulli, coefficients binomiaux
Contexte
Épreuve de BernoulliExpérience à deux issues : Succès (prob. p) ou Échec (prob. 1−p)
Schéma de Bernoullin épreuves de Bernoulli identiques et indépendantes
X ~ B(n, p)X = nombre de succès parmi n épreuves (0 ≤ X ≤ n)
Probabilité & formules
P(X = k), pour k ∈ {0,…,n}
P(X=k) = C(n,k) · pᵏ · (1−p)ⁿ⁻ᵏ
Espérance
E(X) = np
Variance
V(X) = np(1−p)
Écart-type
σ(X) = √(np(1−p))
Coefficients binomiaux
Définition
C(n,k) = n! / (k!·(n−k)!)
= nombre de façons de choisir k éléments parmi n
C(n,0) = C(n,n) = 1
C(n,1) = n
C(n,k) = C(n, n−k)
Relation de Pascal (triangle)
C(n,k) + C(n,k+1) = C(n+1, k+1)

Logique & Raisonnement

Connecteurs, implications, méthodes
Connecteurs logiques
ET (∧)P ET Q : vraie si P et Q sont vraies toutes les deux
OU (∨)P OU Q : vraie si au moins l'une est vraie
NON (¬)Négation : NON P est vraie si P est fausse
Implication & équivalence
P ⟹ QImplication : «Si P alors Q» — P est condition suffisante pour Q
P ⟺ QÉquivalence : P ⟹ Q ET Q ⟹ P
RéciproqueSi «P⟹Q» alors la réciproque est «Q⟹P» (pas forcément vraie !)
Contraposée«P⟹Q» est équivalent à «non Q ⟹ non P»
Cond. nécessaireP ⟹ Q : Q est nécessaire pour P
Cond. suffisanteP ⟹ Q : P est suffisante pour Q
Quantificateurs
∀ (pour tout)∀x∈E, P(x) : P est vraie pour tout x de E
∃ (il existe)∃x∈E, P(x) : il existe au moins un x dans E tel que P(x) est vraie
Négation de ∀NON(∀x, P(x)) ⟺ ∃x, NON P(x)
Négation de ∃NON(∃x, P(x)) ⟺ ∀x, NON P(x)
Types de raisonnements
Par contraposéeProuver «P⟹Q» en montrant «non Q ⟹ non P»
Par l'absurdeSupposer NON Q et aboutir à une contradiction
Par disjonctionTraiter séparément plusieurs cas exhaustifs
Contre-exempleUn seul cas où P est fausse suffit à infirmer «∀x, P(x)»
Statut des lettres & égalités
IdentitéÉgalité vraie pour toutes valeurs des variables
ÉquationÉgalité où x est une inconnue à déterminer
