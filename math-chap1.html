🔢 Partie 1 — Cas général

Définition Une suite numérique est une fonction u : ℕ → ℝ qui à tout entier naturel n associe un nombre réel noté un (lu « u indice n »). On note la suite (un).
  • un est le terme de rang n ou terme général.
  • Le premier terme est souvent u0 (parfois u1).
Exemple La suite un = n² − 4n + 3 donne : u0 = 3 · u1 = 0 · u2 = −1 · u3 = 0 · u4 = 3

📜 Deux façons de définir une suite

Type de définitionPrincipeExemple
Expliciteun s’écrit directement en fonction de n : on peut calculer n’importe quel terme tout de suite.un = √(n+3)
Par récurrenceOn donne le premier terme ET une relation qui calcule un terme à partir du précédent : un+1 = f(un). Il faut calculer dans l’ordre.vn+1 = vn² − 3 et v0 = 0
Astuce Avec une formule explicite, tu peux calculer u1000 directement. Avec une formule récurrente, il faut passer par u0, u1, …, u999 avant !

📈 Sens de variation d’une suite

Une suite (un) définie sur ℕ est :

TypeCondition pour tout n ∈ ℕ
🟢 Croissanteun+1 ≥ un
🔴 Décroissanteun+1 ≤ un
⚪ Constanteun+1 = un
🔵 MonotoneSi elle est croissante OU décroissante
🟡 Strictement monotoneInégalités strictes (> ou <)
🛠️ Méthode clé : Pour étudier le sens de variation, on étudie le signe de la différence
un+1 − un
  • Si cette différence est positive (≥ 0) → la suite est croissante.
  • Si elle est négative (≤ 0) → la suite est décroissante.
  • Si un > 0 pour tout n, on peut aussi comparer le quotient un+1/un à 1.
Attention Si une suite n’est ni croissante ni décroissante (ex : (−1)n qui oscille entre 1 et −1), on dit qu’elle est non monotone.

➕ Partie 2 — Suites arithmétiques

Définition Une suite (un) est arithmétique s’il existe un réel r appelé raison tel que, pour tout entier n :
un+1 = un + r
On passe d’un terme au suivant en ajoutant toujours le même nombre r.
Exemple Si u0 = 2 et r = 5 : u0=2, u1=7, u2=12, u3=17…

🧩 Formule du terme général

un = u0 + n × r

Cas général (pour partir du terme up plutôt que u0) :

un = up + (n − p) × r
Propriété Pour qu’une suite (un) soit arithmétique, il faut et il suffit que la différence un+1 − un soit constante (cette constante est la raison r).

📊 Variations d’une suite arithmétique

Valeur de la raison rNature de la suiteAllure des points (n, un)
r > 0🟢 Strictement croissanteLes points sont
alignés !
r < 0🔴 Strictement décroissante
r = 0⚪ Constante
Astuce Comme un = u0 + n·r est une fonction affine de n, les points (n, un) sont alignés sur une droite de pente r. C’est un excellent moyen de vérifier graphiquement !

➕ Somme des termes d’une suite arithmétique

S = u0 + u1 + ··· + un = (n+1)(u0 + un)2

ou encore : S = nombre de termes × (1er terme + dernier terme)2

Exemple Somme des 101 premiers entiers de 0 à 100 : c’est la suite arithmétique un = n (raison r = 1), de u0=0 à u100=100. S = 101 × (0 + 100) / 2 = 5050.
💡 Piège classique : Le nombre de termes de u0 à un est n + 1 (et non n). Pense à compter le terme de départ !

✖️ Partie 3 — Suites géométriques

Définition Une suite (un) est géométrique s’il existe un réel q appelé raison tel que, pour tout entier n :
un+1 = un × q
On passe d’un terme au suivant en multipliant toujours par le même nombre q.
Exemple Si u0 = 3 et q = 2 : u0=3, u1=6, u2=12, u3=24, u4=48… (la suite « double » à chaque étape).

🧩 Formule du terme général

un = u0 × qn

Cas général :

un = up × qn − p
Propriété Pour qu’une suite (un) (dont tous les termes sont non nuls) soit géométrique, il faut et il suffit que le quotient un+1 / un soit constant (cette constante est la raison q).

📊 Variations de la suite géométrique (qn)

Valeur de qComportement de (qn)
q > 1🟢 Strictement croissante (ex : 2n → 1,2,4,8,16…)
0 < q < 1🔴 Strictement décroissante (ex : (1/2)n → 1 ; 0,5 ; 0,25…)
q = 1⚪ Constante (tous les termes valent 1)
q = 0⚪ Constante à partir du rang 1 (0, 0, 0…)
q < 0⚠️ Non monotone : les termes alternent entre positifs et négatifs (ex : (−2)n)
Attention Le sens de variation de (un) dépend aussi du signe de u0 !
  • Si u0 > 0, (un) varie dans le même sens que (qn).
  • Si u0 < 0, (un) varie en sens contraire de (qn).

➕ Somme des termes d’une suite géométrique

Si q ≠ 1 :

S = u0 + u1 + ··· + un = u0 × 1 − qn+11 − q

ou encore : S = 1er terme × 1 − qnombre de termes1 − q

Si q = 1 : S = (n+1) × u0 (suite constante).

Exemple Somme S = 1 + 2 + 4 + 8 + 16 + 32. C’est une suite géométrique de premier terme u0=1, raison q=2, et 6 termes. S = 1 × (1 − 26)/(1 − 2) = (1 − 64)/(−1) = 63.

🎯 Partie 4 — Comportement global : Bornes

🔎 3 méthodes pour étudier les variations

① Méthode algébrique On compare deux termes consécutifs en étudiant le signe de un+1 − un. Si tous les un sont strictement positifs, on peut aussi comparer un+1/un à 1.
② Méthode fonctionnelle Si la suite est définie par un = f(n) avec f une fonction connue (ex : n², √n, 1/n…), on étudie les variations de f sur [0 ; +∞[ puis on en déduit celles de la suite.
③ Méthode par récurrence Pour une suite définie par un+1 = f(un), on démontre par le principe de récurrence que, pour tout n, un+1 ≥ un (ou ≤).

📏 Suites majorées, minorées, bornées

Définition Une suite (un) est dite :
TermeCondition
Majorée 📈Il existe un réel M tel que pour tout n ∈ ℕ, un ≤ M. Le nombre M est appelé un majorant.
Minorée 📉Il existe un réel m tel que pour tout n ∈ ℕ, un ≥ m. Le nombre m est appelé un minorant.
Bornée 📦Si la suite est à la fois majorée et minorée.
Propriétés utiles
  • Une suite majorée admet une infinité de majorants : si M est un majorant, tout réel supérieur à M est aussi un majorant. (Même chose pour les minorants.)
  • Une suite peut n’être ni majorée ni minorée (ex : un = (−1)n·n qui tend vers ±∞).
  • Toute suite croissante est minorée par son premier terme.
  • Toute suite décroissante est majorée par son premier terme.
Exemple La suite un = 1/(n+1) est :
  • Décroissante (un+1 − un < 0),
  • Majorée par 1 (son premier terme u0 = 1),
  • Minorée par 0 (tous les termes sont positifs),
  • donc bornée 🎉.

🧠 Les 8 commandements des suites

  1. 🔹 Une suite arithmétique = on ajoute toujours le même nombre (la raison r).
  2. 🔹 Une suite géométrique = on multiplie toujours par le même nombre (la raison q).
  3. 🔹 Pour démontrer arithmétique : montre que un+1 − un est constant.
  4. 🔹 Pour démontrer géométrique : montre que un+1/un est constant (et un ≠ 0).
  5. 🔹 Pour les variations : étudie le signe de un+1 − un.
  6. 🔹 N’oublie jamais le signe de u0 pour les variations géométriques !
  7. 🔹 Somme arithmétique : (nombre de termes) × (premier + dernier) / 2.
  8. 🔹 Somme géométrique : premier terme × (1 − qnbre termes) / (1 − q).
