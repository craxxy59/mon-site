🔊 AirDrop Sonore Pro



📖 Mode d'emploi

1️⃣ Appareil 1 : clique sur Créer une session
2️⃣ Appareil 2 : clique sur Rejoindre
3️⃣ Approche les appareils (moins d'1 mètre)
4️⃣ Le son ultrasonique détecte la session
5️⃣ Le transfert se fait automatiquement

⚠️ Les deux appareils doivent être sur le même Wi-Fi.
